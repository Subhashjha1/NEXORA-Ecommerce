# NEXORA – Modern E-Commerce Website

NEXORA is a responsive e-commerce frontend project built with HTML, CSS, JavaScript, and Bootstrap. It provides a modern shopping experience with interactive product browsing and cart management.

## Features

- Responsive design for desktop, tablet, and mobile
- Product search functionality
- Category-based product filtering
- Price sorting (Low to High / High to Low)
- Product details modal
- Add to Cart and quantity management
- Wishlist functionality
- Shopping cart drawer
- LocalStorage for cart and wishlist data
- Demo checkout experience

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- LocalStorage

## Project Structure

Nexora-Ecommerce/

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the NEXORA website.

## Project Purpose

This project was developed to strengthen frontend development skills, including responsive UI design, JavaScript DOM manipulation, event handling, and browser LocalStorage.
